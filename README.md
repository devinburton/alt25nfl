# ALT 2.5 — Final-for-now model

Automatic current NFL week, live consensus totals, weather, recent scoring, points allowed, yards per play, play volume/pace, turnovers, home/away form, injury adjustments, model projection, OVER/UNDER pick, confidence, and a fixed 2.5-point alternate-line cushion.

Required Vercel environment variable:
ODDS_API_KEY

Note: ESPN public endpoints used for schedule/stats/injuries are unofficial/undocumented. If a field is missing, the model skips it rather than inventing data.

This is not a validated profitable betting system. Back-test before relying on it heavily.
